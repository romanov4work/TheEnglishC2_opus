# Модуль "Грамматика" (Grammar)

## Описание

Placeholder-страница. Будет содержать интерактивные уроки грамматики.

## Запланированные темы

- [ ] Present Simple vs Present Continuous
- [ ] Past Simple / Past Continuous
- [ ] Present Perfect
- [ ] "can + be + happening" → progressive forms
- [ ] Modals (must, should, might...)
- [ ] Conditionals (0, 1, 2, 3)
- [ ] Passive Voice
- [ ] Reported Speech
- [ ] C1-C2 сложные конструкции

## Структура

```
app/grammar.tsx — главная (список тем)
app/grammar/[topic].tsx — урок по теме
```

## UI идеи

- Список тем с прогрессом (изучено/не изучено)
- Теория + примеры + упражнения
- Проверка упражнений
